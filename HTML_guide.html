🚀 HTML 기본 문법 가이드

웹 개발의 기초가 되는 핵심 HTML 태그들을 정리한 가이드입니다.

1. HTML 문서의 기본 구조

모든 HTML 문서는 아래와 같은 기본 뼈대를 가집니다.

<!DOCTYPE html> <html lang="ko"> <head> <meta charset="UTF-8"> <title>문서 제목</title> </head> <body> 화면에 보여질 실제 내용이 들어갑니다. </body> </html>

2. 텍스트 관련 태그

<h1> ~ <h6>

제목(Heading)을 나타냅니다. 숫자가 작을수록 글자가 크고 중요합니다.

<h1>가장 큰 제목</h1> <h3>중간 크기 제목</h3>
<p>

단락(Paragraph)을 의미합니다. 일반적인 본문 텍스트를 작성할 때 사용합니다.

<p>이것은 하나의 문단입니다. 위아래로 약간의 여백이 자동으로 생깁니다.</p>
<strong> & <b>

텍스트를 굵게 표시하여 강조할 때 사용합니다. (웹 접근성 측면에서 <strong>이 의미적 강조를 포함하므로 더 권장됩니다.)

<p>이 문장에서 <strong>이 부분만 굵게</strong> 표시됩니다.</p>

이 문장에서 이 부분만 굵게 표시됩니다.

<pre>

미리 정의된 형식(Preformatted text)을 나타냅니다. 코드에 작성된 띄어쓰기와 줄바꿈을 그대로 화면에 출력합니다.

<pre> 띄어쓰기와 줄바꿈이 그대로 유지됩니다. </pre>
  띄어쓰기와 
    줄바꿈이
  그대로 
유지됩니다.

3. 레이아웃과 그룹화 (블록 vs 인라인)

<div>

블록(Block) 요소입니다. 가로 영역 전체를 차지하며, 레이아웃을 나누거나 여러 태그를 하나의 큰 박스로 묶을 때 주로 사용합니다.

<div style="background-color: lightblue;">첫 번째 박스 영역</div> <div style="background-color: lightpink;">두 번째 박스 영역 (줄이 바뀝니다)</div>
첫 번째 박스 영역
두 번째 박스 영역 (줄이 바뀝니다)
<span>

인라인(Inline) 요소입니다. 콘텐츠의 크기만큼만 공간을 차지하며, 문장 중간에 특정 글자의 색상이나 스타일을 변경할 때 사용합니다.

<p>안녕하세요, <span style="color: red;">홍길동</span>님!</p>

안녕하세요, 홍길동님!

4. 미디어 및 링크 태그

<img>

이미지를 삽입합니다. 닫는 태그가 없는 단일 태그입니다. src(이미지 경로)와 alt(대체 텍스트) 속성이 필수입니다.

<img src="이미지주소.jpg" alt="귀여운 고양이 사진" width="200">
<video>

비디오 영상을 삽입합니다. controls 속성을 넣으면 재생/정지 버튼이 생성됩니다.

<video src="영상주소.mp4" width="300" controls autoplay muted></video>
  • controls : 조작 패널 표시
  • autoplay : 자동 재생 (보통 muted와 함께 써야 크롬 등에서 작동함)
  • muted : 음소거
<a>

다른 페이지로 이동하는 하이퍼링크를 만듭니다. href 속성에 이동할 주소를 적습니다.

<a href="https://www.google.com" target="_blank">구글로 이동 (새창)</a>

5. 표 만들기 태그

표를 구성할 때는 여러 태그를 조합해서 사용합니다.

  • <table> : 표 전체를 감싸는 태그
  • <tr> : 표의 한 줄(Row)을 의미
  • <th> : 제목 셀 (굵게, 가운데 정렬됨)
  • <td> : 일반 데이터 셀
<table border="1"> <tr> <th>이름</th> <th>나이</th> </tr> <tr> <td>홍길동</td> <td>20</td> </tr> </table>
이름 나이
홍길동 20
이순신 35
